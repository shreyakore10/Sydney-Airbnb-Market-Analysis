# Sydney Airbnb Market Analysis

## Project Overview

This project analyzes Sydney Airbnb listings, pricing, reviews, neighbourhoods, and estimated revenue.

Python and Pandas are used for data extraction, cleaning, and preprocessing. Power BI is used to create an interactive dashboard and visualize key insights.

## Tools Used

- Python
- Pandas
- CSV
- Microsoft Power BI

## Project Workflow

1. Extracted data from CSV files.
2. Cleaned and prepared the data using Python and Pandas.
3. Imported the cleaned data into Power BI.
4. Created KPI cards, charts, slicers, and a map.
5. Analyzed listing distribution, room types, pricing, reviews, and estimated revenue.
