# Sydney Airbnb Market Analysis

An interactive Power BI dashboard exploring Airbnb listings in Sydney, including listing distribution, pricing, room types, reviews, and estimated revenue. Python and Pandas were used for data cleaning and preprocessing, and Power BI was used to build the dashboard.


## Tools Used

- Python
- Pandas
- CSV
- Microsoft Power BI

## Project Workflow

1. Extracted data from CSV files.
2. Cleaned and prepared the data using Python and Pandas.
3. Imported the cleaned data into Power BI.
4. Created KPI cards, charts, slicers, and a map.
5. Analyzed listing distribution, room types, pricing, reviews, and estimated revenue.
